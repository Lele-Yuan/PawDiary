# 来我家吃饭（mealtime）视觉改版总结

## 完成情况

已将「来我家吃饭」模块的整体视觉从绿色主题改为设计稿（Foodee / Qori Dev）的珊瑚红 + 暖奶油风格，4 个任务全部完成。改动仅涉及样式与导航栏颜色，未触碰任何 js、wxml、云函数、数据结构与交互逻辑。

## 主要改动

主题（核心）：重写 `pages/mealtime/mealtime-theme.wxss`，将 8 个 CSS 变量换为珊瑚奶油配色（主色 #EE7A6D、深色 #D85C4E、浅色 #F7C7C0、背景 #FFFBF4、文字 #3C3A42 等），渐变改为珊瑚按钮渐变与暖色头图，新增鼠尾草绿点缀变量 #7E9E8C。公共类的绿色投影统一改为珊瑚色投影，`.tag.cook/.eat/.admin`、`.avatar`、`.chip` 配色暖色化，卡片圆角加大到 28rpx。

页面样式：批量替换 8 个页面 wxss 中硬编码的绿色投影（rgba(90,130,50,*) 等）与浅绿底色（#EAF7D9→#FDECE8、#F4F8EE→#FBF1EC），receipt 页锯齿裁切色 #F2FBEA→#FFFBF4、虚线与备注文本暖色化，dishEdit 上传框虚线暖色化。告警橙、删除红等功能性强调色按预期保留。

导航栏：8 个页面 json 的 `navigationBarBackgroundColor` 由绿色 #8CC63F 改为珊瑚色 #EE7A6D，文字保持白色，统一品牌色。

## 验证

8 个页面 json 通过 JSON.parse 校验；8 个页面 wxss 的主题 @import 均保留；全模块已无任何旧绿色色值残留（7CB342 / 5B9B2E / A8E063 / F2FBEA / 8CC63F / EAF7D9 / F4F8EE 均已清除）。运行态视觉请在微信开发者工具中编译预览确认。

## 说明

因模块样式集中在主题变量与公共类，页面结构零改动即完成整体换肤；样式仍仅通过各页 `@import` 生效，不污染宿主全局。模块实际页面为约饭/点菜/小票等家庭约饭流程，本次按设计稿采用其视觉语言（珊瑚胶囊按钮、大圆角柔投影卡片、暖奶油背景、粗体深色标题），未照搬设计稿中的购物车/商品详情等具体业务组件。
