# DGTI 狗格指标 测试规则总览

> DGTI（Dog Type Indicator）是一套面向宠物狗的「狗格」性格测试，灵感借鉴 MBTI。它以 **5 大模型 × 3 子维度 = 15 个狗格维度**，派生出 **16 种经典狗格人格**，并通过 **24 道题** 进行打分匹配，最终生成结果与 5 维雷达图。

数据源：`miniprogram/pages/dogti/data/dgti-data.js`

---

## 四、算分与匹配算法

### 4.1 维度累加 `calcScores(answers)`

```text
初始化 15 维分数全部为 0
对每个回答 (questionId, optionIndex):
    取出该选项的 scores 对象
    将 scores 中每个维度的值累加到对应维度分上
返回 15 维总得分
```

### 4.2 人格匹配 `calcPersonality(answers)`

1. 调用 `calcScores` 得到 15 维分数；
2. 在每个模型内部取「得分最高」的维度：
   - M1 ∈ {E, I, A}
   - M2 ∈ {F, S, M}
   - M3 ∈ {C, G, D}
   - M4 ∈ {P, Z, T}
   - M5 ∈ {R, B, H}
3. 取前 3 个主维度 `[m1, m2, m3]`，**按字母排序后用 `+` 拼接** 得到 `top3`；
4. **精确匹配**：在 16 个人格中查找 `code` 字段排序后等于 `top3` 的；
5. **模糊回退**：若无精确命中，用 `[m1, m2, m3, m4, m5]` 与每个人格的 `code` 拆分维度求 **重合维度数**，取重合最多的那个；若仍无法判断，则默认返回第一个人格（`qi-tian` 齐天疯狗型）。

### 4.3 五维雷达 `calcRadarScores(scores)`

将 15 维原始分加权映射为 5 个雷达轴（最终值钳制在 5–99 之间）：

| 雷达轴 | 含义 | 计算公式（s 表示 15 维分数） |
| :-- | :-- | :-- |
| social | 社交力 | `s.E*1.0 + s.F*0.5 + s.H*0.3` |
| danger | 危险度 | `s.A*1.0 + s.C*0.4 + s.D*0.2` |
| destroy | 破坏力 | `s.D*1.0 + s.Z*0.5 + s.B*0.3` |
| clingy | 黏人度 | `s.M*1.0 + s.H*0.7 + s.F*0.3` |
| mental | 智商/稳定 | `s.S*1.0 + s.T*0.8 + s.G*0.3 - s.Z*0.4 - s.F*0.2` |

归一化方式：`clamp( round(raw / 25 * 100), 5, 99 )`，其中 25 为对最大原始值的经验估计。

## 五、流程总览

```text
答完 24 题
   │
   ▼
calcScores(answers)            → 15 维原始分
   │
   ├─► calcPersonality(answers) → 命中 / 回退到 16 人格之一
   │       │
   │       └─► 渲染结果页：人格名、身份、tagline、traits、推荐犬种、社/危/破/黏/智指数卡
   │
   └─► calcRadarScores(scores) → 5 维雷达图（动态值）
              │
              └─► 渲染雷达图 + 分享海报中的小型雷达
```
