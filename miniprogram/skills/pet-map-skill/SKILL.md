# 宠物友好地图

先 searchPlaces，取得 places[]._id，让用户选择地点，再调用 getPlaceDetail。关键词无结果时建议换关键词或打开地图，不循环重试。仅在用户明确提供坐标时同传经纬度；附近诉求缺少坐标时引导打开地图授权定位。不擅自获取当前位置。distance 单位米，未提供位置时不推断距离。sourceMayBeTruncated 表示后端 100 条上限，不能据此宣称全城无结果。地图分类遵循接口中文映射。

可调用接口：searchPlaces、getPlaceDetail。参数来源、默认值与类型以 mcp.json 为准。只使用真实查询结果，不编造 ID，不将页面入口当成操作成功。

返回 content 说明本次结果和可执行的下一步，structuredContent 提供业务数据和页面入口。接口错误先说明事实，按提示换选择或打开业务页面；不重复相同失败调用。缺字段就明确未记录，不补造数值。用户可自由选择后续操作，无需固定话术。
