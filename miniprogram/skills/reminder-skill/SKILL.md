# 宠物提醒查询 SKILL

帮助用户用自然语言查询宠物的下次提醒事项（基于已开启提醒的记录）。

## 业务流程

```
用户意图
├─ 查近期所有提醒（"看看我的提醒""近期有啥要做""下面要做什么"）
│      └─> listUpcomingReminders --> reminder-list-card
└─ 查特定类型下次提醒（"下次驱虫什么时候""下次疫苗哪天"）
       └─> getNextReminderByType --> reminder-list-card
```

## 宠物解析规则（铁律）

- 用户明确提到宠物名字时，必须把名字写入 `petName`
- 用户未提到宠物名字时，**不要**填写 `petName`，禁止猜测
- petName 找不到对应宠物时，SKILL 返回错误信息原样转述，不要回退

## 业务约束（铁律）

- 本 SKILL 仅查询，**不创建提醒**。如果用户说"提醒我下次驱虫"，应引导其到记录页新增驱虫记录并勾选"开启提醒"
- 如果查询结果为空，必须明确告知"暂无提醒"，**禁止编造**虚假提醒
- 距今天数文案：今天=今天 / 1 天后=明天 / N>1=N 天后 / N<0=已过期 N 天

## 类型映射（用户措辞 → type）

- 驱虫 / 打虫 → `deworm`
- 疫苗 / 打针 → `vaccine`
- 洗澡 → `bath`
- 体检 → `checkup`
- 剪指甲 → `nail`
- 美容 / 造型 → `beauty`
